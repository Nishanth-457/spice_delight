STEP 1 — Copy your food images
-----------------------------------------------
Take all images from your original project
(PannerTikka.jpg, Chicken65.jpg, Banner.jpg etc.)
and paste them into:

    spice_delight/static/images/


STEP 2 — Install Python packages
-----------------------------------------------
Open terminal inside the spice_delight folder and run:

    pip install -r requirements.txt


STEP 3 — Set up the database
-----------------------------------------------
Open MySQL Workbench.
Click File > Open SQL Script > select spice_delight.sql
Press the Run (lightning bolt) button.

This creates:
  - spice_delight database
  - 4 tables (users, menu_items, orders, order_items)
  - 36 menu items already loaded
  - 1 admin account already created


STEP 4 — Set your MySQL password in app.py
-----------------------------------------------
Open app.py and look for this line near the top:

    app.config['MYSQL_PASSWORD'] = ''

If your MySQL has a password, type it between the quotes.
If no password (most college setups), leave it blank.


STEP 5 — Verify everything is working
-----------------------------------------------
Run the checker script:

    python check_setup.py

All items should show a checkmark.


STEP 6 — Start the website!
-----------------------------------------------
Run:
    python app.py

Open your browser and go to:
    http://127.0.0.1:5000
